# AI分身マッチングMVP

AIとの会話を通じて、あなたの性格や価値観を分析し、相性の良さそうな候補者を1人紹介するローカルMVPです。

## 現在のバージョン

**ver0.0.4**

### ver0.0.3の主な追加機能

* アプリ内バージョン表示
* ログ保存機能
* ログ保存同意画面
* セッション管理機能
* 「最初からやり直す」機能
* 「終わる」機能
* session_id によるログ追跡

### ver0.0.4の主な追加機能
 - UIをLINE風にした
 - アンケートへ遷移

## 概要

* Streamlit で簡単なチャットUIを提供します。
* ユーザーと AI が会話を進めることで、性格や価値観を分析します。
* 事前に用意した候補者データから、最も相性の良い1人を提示します。
* データベースは使わず、ローカルの JSON ファイルを利用します。

## セットアップ

1. リポジトリをクローンまたはワークスペースに配置します。
2. Python 環境を用意します。
3. 依存パッケージをインストールします。

```bash
pip install -r requirements.txt
```

4. ルートに `.env` ファイルを作成し、以下の環境変数を設定します。

```env
OPENAI_API_KEY=your_api_key_here
OPENAI_MODEL=gpt-5.4-mini
OPENAI_EMBEDDING_MODEL=text-embedding-3-small
```

## 実行方法

```bash
python -m streamlit run app.py
```

## 必要な環境変数

* OPENAI_API_KEY
* OPENAI_MODEL
* OPENAI_EMBEDDING_MODEL

## ログ保存について

本アプリでは、品質改善・動作確認のため、ユーザーの同意後にログを保存します。

保存対象：

* チャット履歴
* 分析結果
* マッチング結果
* デバッグ情報
* エラー情報

## ログ保存先

```text
logs/
└─ v0.0.3/
   ├─ sessions/
   ├─ debug/
   └─ errors/
```

### sessions

人間確認用ログ（Markdown）

保存内容：

* セッション情報
* チャット履歴
* 分析結果
* マッチング結果

### debug

デバッグ用ログ（JSON Lines）

保存内容：

* 分析開始
* 分析完了
* マッチング開始
* マッチング完了
* セッション開始
* セッション終了
* その他デバッグイベント

### errors

エラーログ（JSON Lines）

保存内容：

* APIエラー
* ログ保存エラー
* JSONエラー
* その他例外

## セッション管理

各セッションには一意の session_id が付与されます。

例：

```text
session_20260609_123456_a8f3c2
```

session_id は以下のログで共通利用されます。

* session Markdownログ
* debugログ
* errorログ

## GitHubにアップロードしないファイル

以下のファイル・フォルダは GitHub にアップロードしません。

```text
.env
logs/
.streamlit/secrets.toml
.claude/settings.local.json
```
